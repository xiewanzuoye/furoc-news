**清华未来机器人兴趣团队**

FuRoc（Future Robotics Club）清华大学未来机器人兴趣团队聚焦具身智能与机器人领域，连接技术研究、学术创新、产业资源与技术社区。

我们希望搭建一个面向未来机器人的学生平台，让更多同学在这里接触前沿方向、参与真实项目、连接行业资源，并与一群优秀的人一起做有长期价值的事情。

如果你对机器人、AI、科技创新、产业协作、社区建设感兴趣，欢迎加入 FuRoc。

本轮招新，面向两个核心中心与两个赛事队展开：

•        科技活动中心

•        综合管理中心

•        THMOS-机器人足球队

•        Tinker-家用服务机器人队

本文介绍两个核心中心。

你加入的不只是一个学生社团，

更是一个正在生长中的机器人生态社区！

**科技活动中心**

![Image](images/img_015.png)

      科技活动中心是 FuRoC 负责科技活动策划、组织与长期建设的核心组织，聚焦具身智能与机器人领域。

      我们希望把技术实践、活动组织和开源协作连接起来：让更多同学走近机器人，也让每一次活动、每一份资料、每一次项目尝试都能留下可持续的积累。

      此前，FuRoC 举办清华未来机器人挑战赛，以“极致运控”为主题，校内外多支队伍在紧凑的开发周期内完成挑战并顺利完赛；开源社区已构成社群并稳步积累。这只是一个开始。

      本学期，科技活动中心将继续完善赛事、科普与开源协作三条线，并首次更系统地搭建团队机制。你加入的不只是一个执行团队，更是一群愿意一起把活动品牌、组织机制与技术生态慢慢做起来的人。

科技活动中心下设三个部门：

![Image](images/img_016.png)

**1**

**科创赛事部**

**部门定位：**

围绕机器人与具身智能相关赛事，参与从策划到落地的全过程；在已有赛事经验的基础上，持续打磨赛事品质、参赛体验与资料沉淀。

**你将参与什么：**

• 参与赛事主题、赛制与评审流程的设计

• 推进宣讲、报名、培训、比赛日执行等关键环节

• 协调场地、评委与合作资源

• 完成赛后复盘，沉淀可持续复用的赛事资料与流程

**我们期待你：**

• 对机器人、具身智能或相关竞赛感兴趣

• 有责任心，能围绕时间节点推进任务

• 乐于沟通协作，愿意承担统筹、协调与现场执行工作

• 有活动组织、学生工作或竞赛经历更佳

**2**

**科普活动部**

**部门定位：**

面向校内同学策划具身智能与机器人相关的科普活动，把复杂的技术与产业话题讲得更清楚、更有趣、更容易参与。

**你将参与什么：**

• 策划讲座、分享会、workshop、体验活动等内容

• 将专业内容转化为生动、低门槛的校园活动

• 与其他部门合作，组织面向新手的入门活动

• 收集活动反馈，逐步完善知识库与活动流程

**我们期待你：**

• 对 AI、机器人或科技产业感兴趣，不要求是纯研发方向

• 愿意做技术传播、内容策划与活动组织

• 具备跨领域学习、沟通协作和执行能力

• 有内容创作、主持、宣发、设计等经验更佳

**3**

**开源社区部**

**部门定位：**

围绕 FuRoC 的真实项目与技术实践，探索更有效的开源协作方式，把有价值的代码、文档和经验沉淀下来，方便后来者学习、使用与继续迭代。

开源社区部不是一个泛泛的技术交流群。我们更希望从小而具体的共同目标出发，逐步建立清晰的成员分工、协作节奏与长期积累。

**你将参与什么：**

• 建设和维护代码仓库、文档体系与协作规范

• 围绕具体项目整理教程、README、模板和项目说明

• 参与小规模开源共创、技术分享与项目复盘

• 一起探索更适合社团的开源协作机制，让成果真正被复用

**我们期待你：**

• 认可开源协作与长期建设的价值

• 愿意做项目维护、技术文档、工具链建设或社区运营中的任一部分

• 有 Git/GitHub、技术项目或技术文档经验更佳

• 即使经验不多，只要愿意学习、愿意持续投入，也欢迎加入

**为什么加入科技活动中心**

这里没有一套已经写好的答案。

赛事怎样更有特色，科普怎样真正降低门槛，开源社区怎样形成持续的共同产出，都需要一群人一起实践、复盘和完善。

如果你希望在具身智能与机器人领域做些真正落地的事，也愿意参与建立一个长期成长的团队，欢迎加入 FuRoC 科技活动中心。

**综合管理中心**

![Image](images/img_022.png)

综合管理中心是 FuRoc 的运营核心、资源枢纽。

我们负责推动社团项目与活动顺利落地，为 FuRoc 的赛事、科普活动和技术项目提供持续支持。

**综合管理中心连接：**

**•        项目推进**

**•        产业资源**

**•        品牌传播**

**•        组织协作**

通过整合资源与搭建机制，帮助 FuRoc 的技术社区、赛事活动和产业合作长期发展。

在这里，你不仅是在参与社团工作，更是在参与一个机器人生态社区的建设。

**综合管理中心下设四大部门**

**•        项目部**

**•        财务部**

**•        联络部**

**•        宣传部**

**1**

**项目部**

**部门定位****：**

项目部负责 FuRoc 整体项目的管理与支持，是连接科技活动中心、技术项目与外部合作的核心中枢。

**主要工作****：**

• 梳理 FuRoc 各类项目（赛事 / 活动 / 技术 / 合作），建立项目台账

• 跟进项目进度与关键节点，推动项目按计划落地

• 协调科技活动中心及各部门之间的协作与资源分配

• 搭建项目流程与管理机制（立项 / 执行 / 复盘）

• 沉淀项目经验与成果（文档、模板、方法论），提升组织效率

**我们希望你****：**

•    对项目管理、组织协作或团队运作有兴趣

•    具备基本的逻辑能力与结构化思维

•    做事靠谱，有执行力和时间观念

•    善于沟通，能推动不同人一起把事情做成

•    愿意投入时间参与长期建设

**2**

**财务部**

**部门定位：**

财务部负责 FuRoc 的经费管理与资源保障，为社团活动与项目提供稳定、规范的运营支持。

**主要工作：**

•        活动预算制定与管理

•        经费报销与财务核算

•        物资采购与资产管理

•        社团财务记录与规划

**我们希望你：**

•        做事细心、负责

•        具备良好的执行力与规范意识

•        对组织管理或财务管理感兴趣

**3**

**联络部**

**部门定位：**

联络部负责 FuRoc 的内外部连接：一方面增强团队内部凝聚力，另一方面推动社团与企业、科研机构和行业伙伴建立合作关系。

**主要工作：**

外联方向

•        对接企业与机构合作资源

•        邀请嘉宾与合作伙伴参与活动

•        推动机器人产业合作项目

•        维护社团合作伙伴关系

内联方向

•        组织社团内部交流活动

•        促进不同部门成员之间的熟悉与合作

•        活跃社团氛围，增强团队凝聚力

**我们希望你：**

•        善于沟通表达

•        对科技产业或创业生态感兴趣

•        乐于拓展资源与建立合作

**3**

**宣传部**

**部门定位：**

宣传部负责 FuRoc 的品牌建设与内容传播，提升社团在机器人领域的影响力。

**主要工作：**

•        社团品牌与内容运营

•        活动宣传与科技内容制作

•        新媒体平台运营

•        社团视觉与宣传物料设计

**我们希望你：**

•        对内容创作 / 设计 / 新媒体运营感兴趣

•        有一定创意表达能力

•        愿意参与社团品牌建设
